YOUR COMPUTER · YOUR DATA

Use the full app on your Windows laptop.

Start it once on your own PC. Your dashboard, telemetry and approved actions run locally.

WINDOWS x64 / ARM64
01

Choose your Windows download

Python is included. Choose x64 for Intel or AMD, or ARM64 for Snapdragon. Both are small, self-contained beta packages.

Intel / AMD · x64 (.zip, 11.6 MB) ↓ Snapdragon · ARM64 (.zip, 10.9 MB) ↓ Release notes, checksums & assets ↗
02

Extract & launch

Choose Extract All, open the Kshetrajna folder inside it, then open Launch.cmd. No Python or Git installation is needed. For a per-user copy and desktop shortcut, run Install.cmd.

03

Open your local dashboard

The launcher opens it automatically. Enable collection and the desired controls in Privacy. Review and approve each action on your computer.

Open my local dashboard ↗
Optional: add AI conversation, without an API key

Install Ollama for Windows and download a local model suitable for your device. Start Kshetrajna, select the installed model in Chat, and enable local AI. Live PC tools work without a model.

Setup help, updates and stopping the app

If the local page cannot be reached, start Launch.cmd first. Open Console.cmd for startup errors. If port 8765 is busy, use Console.cmd --port 8767. To stop, choose Quit Kshetrajna in Privacy.

Prefer running from source?

Download the source, install Python 3.13, extract, and open start_here.cmd.

Native x64 and ARM64 packages passed source and packaged-app checks. These are unsigned beta archives with local setup. The hosted site does not receive your dashboard data or control your PC.
