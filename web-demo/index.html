WINDOWS x64 / ARM64
01

Choose your Windows download

Python is included. Choose x64 for Intel or AMD, or ARM64 for Snapdragon. Both are small, self-contained beta packages.

Intel / AMD · x64 ↓Snapdragon · ARM64 ↓Release notes & checksums ↗
02

Extract & launch

Choose Extract All, open the Kshetrajna folder inside it, then open Launch.cmd. No Python or Git installation is needed. For a per-user copy and desktop shortcut, run Install.cmd.

03

Open your local dashboard

The launcher opens it automatically. Enable collection and the desired controls in Privacy. Review and approve each action on your computer.

Open my local dashboard ↗
Optional: add AI conversation, without an API key

Install Ollama for Windows and download a local model suitable for your device. Start Kshetrajna, select the installed model in Chat, and enable local AI. Live PC tools work without a model. Model speed and runtime compatibility depend on your hardware; Snapdragon inference needs separate device testing.

Setup help, updates and stopping the app

If the local page cannot be reached, start Launch.cmd first. Open Console.cmd for startup errors. If port 8765 is busy, use Console.cmd --port 8767 and open the printed address. To stop, choose Quit Kshetrajna in Privacy. Download a fresh version for updates; history stays in your Windows user profile. Full setup guide ↗

Prefer running from source?

Download the source, install Python 3.13 for your Windows architecture, extract the source, and open start_here.cmd. The prebuilt downloads above already include Python.

Native x64 and ARM64 packages passed source and packaged-app checks. These are unsigned beta archives with local setup, not signed MSI/EXE installers. The hosted site does not receive your dashboard data or control your PC. The local link opens the app on the device you are browsing from.
