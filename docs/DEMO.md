# End-to-end demonstration script

This script uses synthetic data and isolated temporary storage. It does not
scan personal folders or modify real processes/files.

1. Double-click `run_demo.cmd` and open the local dashboard.
2. Point out the `SYNTHETIC DEMO / No Windows changes` banner, seeded CPU/RAM,
   app routines, evidence score, coverage, and replay sample count.
3. Review and approve the simulated priority trial, then use **Undo now**.
4. Save and activate a workspace board. Explain that it changes the dashboard
   board only; it does not arrange native Windows windows.
5. Scroll to File Intelligence. The demo roots and catalog are synthetic.
6. In Sort AI, choose a root, enable **Create category folders**, generate the
   plan, inspect reasons/confidence/destinations, deselect one item, and apply
   the remaining simulated batch. Use **Undo eligible changes**.
7. Open Windows maintenance, review a simulated action, and show that no tool
   is launched in demo mode.
8. Change Development to Meeting or Creative and show the context changes.
9. Download the report before closing. It states the data source and the
   limitation that synthetic metrics are not benchmarks.

For a real Windows walkthrough, use `run.cmd`, enable collection explicitly,
and use only controlled test processes/folders for any live mutation. Do not
use a personal folder or application merely to demonstrate a mutation.
